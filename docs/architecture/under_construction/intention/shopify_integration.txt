This page will be used for managing the shopify shop linkage the current workspace holds, a user part of a workspace will be able to:

* see the shopify integrations
* edit the shopify integrations
* delete a shopify integration
* create a shopify integration

The page will use it's own header. thus it will turn off the slide surface header, example at : /Users/davidloorenz/Desktop/Developer/BeyoApps_2025/ManagerBeyo-app/frontend/packages/tasks/src/pages/TaskDetailSlidePage.tsx

This page will be compose of three containers each with a header a body and a footer.
This page will treat this containers as main pages, one container rendering the list of shopify integrations the other rendering the shopify integration detail. The last container is the form creation for a shopify integration.
When a user enters to this page it first loads the shopify integration listing, if the user taps into a shopify integration the containers slide and the user is now at the shopify integration detail container. If the user taps on the creation button the user will be taken to the creation form contianer
This containers will be build as separate containers which will be reuse by other pages later on. in this page the containers slide animation is ruled by the index at which the container is at ( like a image carousel sliding component ). example of this slide implementation: /Users/davidloorenz/Desktop/Developer/BeyoApps_2025/ManagerBeyo-app/frontend/packages/task-customer-coordination/src/pages/CustomerCoordinationEmailInboxPage.tsx ( EmailThreadCarousel )
